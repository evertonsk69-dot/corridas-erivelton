# Corridas Erivelton

Aplicativo web para solicitação de corridas particulares com Erivelton Santos.

## Recursos
- Solicitação de corrida pelo celular
- Origem e destino
- Estimativa de preço
- Corrida imediata ou agendada
- Opção de ida e volta
- Resumo do pedido
- Envio direto para o WhatsApp
- Botão para ligação
- Instalação como app/PWA em navegadores compatíveis

## Valores configurados
- Tarifa inicial: R$ 5,00
- R$ 2,50 por km
- Valor mínimo: R$ 15,00
